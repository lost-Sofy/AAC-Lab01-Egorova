##Контрольные вопросы
1.Благодаря .NET, который предоставляет программе инструменты для получения некоторых сведений о компьютере. Но сама программа их получить не может.
2.Операционная система выступает посредником между программой и данными о железе, на котором работает. ОС отвечает за доступ к этим данным.
3.64-битные ОС используют сложную архитектуру, что позволяет работать с большим количеством данных и выполнять операции быстро. Большинство современных компьютеров используют как раз такую ОС.
4.Environment.ProcessorCount возвращает количество  логических  потоков. Значение метода не обязательно совпадает с числом физических ядер.(Наглядно про совпадение в ##3)
5.Память процесса это пространство, которое создается во время запуска программы. Пространство имеет отдельную память, которая не связана с памятью компьютера.
6.Потому что информация которую выводит программа зависит от железа на котором она запускается. Информация так же может совпадать, но это уже зависит от схожести компьютеров.
##Итоговый вывод 
Программа может выводить информацию компьютера без текста или не запрашивая данные. Для этого она делает запрос, используя некоторые инструменты, у посредника - ОС. В итоге полученная информация может отличаться. Это происходит потому что программа берет данные из железа на котором ее запускают.
